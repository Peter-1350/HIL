# 基础VCU与整车模型闭环交互实验（可编辑完整版）
实验 1 加速踏板交互闭环实验
1.1 实验目的
验证 Mini-HIL 模拟踏板信号与实物 VCU 信号采集、解析逻辑；
明确踏板开度→VCU 需求扭矩→整车动力系统双向闭环交互规律；
获取双路踏板正常工作基准波形，为后续踏板故障注入实验提供对照数据；
统计本道测试工序工时，用于后续工位线平衡、价值流分析。
1.2 VCU - 整车闭环交互链路
HIL DA 板输出 0~5V 双路踏板模拟电压 → VCU 模拟量采集模块读取信号 → VCU 踏板处理算法解析实际踏板开度 → VCU 扭矩管理模块计算驱动需求扭矩 → CAN 报文下发至 SoftECU-MCU 电机模型 → 整车 Powertrain 动力总成更新电机转速、实时车速 → 车速、SOC 信号回传 VCU 形成毫秒级实时闭环。
1.3 实验测试步骤
完成通用前置全部软硬件配置，加载 WLTC 基础工况；
静态定点测试（5 组梯度踏板）
（1）HIL 端分别设置双路踏板 0%、25%、50%、75%、100% 对应标准电压；
（2）每组工况稳定运行 60s，保持整车无加速 / 减速扰动；
（3）DAS 同步记录全时序波形，每组单独命名保存文件；
动态连续工况测试
（1）加载完整 WLTC 循环，踏板开度随工况自动连续升降；
（2）全程不间断采集踏板电压、扭矩、车速、SOC 时序数据；
每组测试完成后，记录人工修改参数、等待仿真、导出数据的全部工时。
1.4 核心采集指标
两路加速踏板模拟输入电压、VCU 内部识别踏板百分比、VCU 输出需求驱动扭矩、MCU 实际执行扭矩、整车实时车速、动力电池 SOC 值、踏板两路信号差值。
1.5 实验预期结果
双路踏板电压同步变化，差值在允许阈值内时 VCU 正常解析开度；
踏板开度提升，VCU 输出扭矩线性上升，整车车速同步增加；
踏板开度归零后，VCU 进入能量回收逻辑，车速缓慢下降。
实验 2 挡位系列交互实验（3 个子实验）
子实验 2-1 人工挡位信号采集实验
2.1.1 实验目的
验证 HIL 数字挡位信号输入后，VCU 挡位识别、扭矩限制基础交互逻辑，采集 P/R/N/D 各挡位标准工作基线。
2.1.2 闭环交互链路
HIL DIO 板输出 P/R/N/D 挡位数字电平信号 → VCU 档位信号处理模块识别 Gear_State 状态 → VCU 扭矩模块输出对应挡位扭矩限制指令 → CAN 报文下发 MCU → 整车传动 Driveline 模块执行驻车 / 前进 / 倒车动力学反馈，车速信号回传 VCU。
2.1.3 测试步骤
软硬件基线环境就绪，无故障正常接线；
依次单独输出 P、R、N、D 单挡位电平，每组稳定运行 30s；
切换挡位时记录 VCU 状态跳转时延，同步存储每组时序数据；
2.1.4 采集指标
挡位输入数字电平、VCU 内部 Gear_State 状态码、VCU 输出扭矩上限、整车稳态最大车速、挡位识别响应时延。
2.1.5 预期结果
P 挡整车扭矩锁止，车速为 0；R 挡允许低速倒车；N 挡无驱动扭矩输出；D 挡正常输出全范围驱动扭矩。
子实验 2-2 换挡时机判断实验
2.2.1 实验目的
验证 VCU 高低速换挡保护逻辑，明确车速与挡位切换的闭环交互约束关系。
2.2.2 测试步骤
固定 D 挡模式，WLTC 工况分别加速至 30km/h、60km/h、90km/h；
高速工况下模拟切换 R 倒挡，观测 VCU 扭矩切断保护动作；
低速＜10km/h 区间反复切换 D/R 挡位，记录扭矩切换时序；
记录各换挡操作下整车车速、扭矩变化曲线。
2.2.3 采集指标
实时车速、当前挡位状态、VCU 输出驱动扭矩、扭矩切断持续时长。
2.2.4 预期结果
车速高于设定阈值时，切换 R 挡 VCU 直接切断驱动扭矩，禁止倒车；低速切换允许小幅倒车扭矩输出。
子实验 2-3 挡位无故障基准采集实验
2.3.1 实验目的
采集正常挡位 IO 电平、CAN 报文标准波形，作为挡位断线、跳变故障的对比基准。
2.3.2 测试步骤
循环切换 P/R/N/D 完整挡位流程，连续运行 180s，保存无故障挡位时序基线文件。
实验 3 真空助力泵闭环交互实验
3.1 实验目的
验证真空度传感器信号与 VCU 真空泵控制闭环逻辑；
获取真空泵启停标准阈值数据，建立传感器正常工作基线。
3.2 闭环交互链路
HIL DA 板输出真空度 0-5V 模拟电压信号 → VCU 模拟量采集读取真空数值 → VCU 附件管理模块判定真空阈值 → 输出真空泵高低边驱动 DO 信号 → HIL 整车 Brake 制动模块更新整车真空压力值 → 真空压力信号回传 VCU 形成闭环调节。
3.3 测试步骤
基线环境搭建完成，无故障仿真；
分三组稳态工况测试：低真空、标准真空、高真空；
每组稳定运行 90s，观测真空泵自动开启、切断动作；
记录真空泵启停对应的真空电压阈值，存储时序波形。
3.4 采集指标
真空传感器输入模拟电压、VCU 真空泵驱动输出电平、整车实时真空度、真空泵启停切换时延。
3.5 预期结果
真空度低于下限阈值时 VCU 输出驱动信号，真空泵启动；真空度达到上限阈值后 VCU 切断输出，真空泵停止工作。
实验 4 DCDC 低压管理闭环实验
4.1 实验目的
验证低压蓄电池信号与 VCU DCDC 充放电控制双向交互逻辑，获取低压系统正常工作基准数据。
4.2 闭环交互链路
HIL DA 板输出 12V 低压蓄电池模拟电压 → VCU 采集低压信号判定亏电 / 满电状态 → VCU 附件模块输出 DCDC 使能驱动信号 → 整车低压负载模型更新电池电压数值 → 低压电压信号回传 VCU 闭环调节。
4.3 测试步骤
无故障基线环境就绪；

采集电压阈值与 DCDC 驱动对应关系，保存波形文件。

4.5 预期结果
低压电压低于设定下限，VCU 开启 DCDC 升压；电压达到标准区间后 DCDC 维持待机；电压过压时 DCDC 切断输出。
实验 5 空调热管理交互实验
5.1 实验目的

5.2 闭环交互链路
HIL DA 板输出蒸发器、电池温度两路模拟信号 → VCU 采集温度数值 → VCU 热管理模块输出空调压缩机驱动信号 → HIL 整车 Environment 环境模块更新舱温、电池温度 → 温度信号持续回传 VCU 动态调节。
5.3 测试步骤
搭建无故障基线仿真环境；
三组稳态工况：高温环境、常温环境、低温环境；

5.5 预期结果
环境 / 电池温度高于制冷阈值时 VCU 开启空调；温度下降至目标区间后自动关闭压缩机。
