# TS-08 上下电基准：时序、指纹与诊断分析（20 ms）

## 结论

本次记录包含 19 个信号、2428 个样本，采样周期约 20 ms、总时长约 48.54 s。记录中完成两次 Key 上电/下电循环，并在第二次上电稳定后将 `BMS__BattContFail` 置位 3.32 s。

> 编号校正：本报告对应**实验 8（上下电基准）**。原始录波文件保留设备端生成的 `TS-06-上下电基准` 文件名，仅作为数据来源标识，不代表本实验编号。

可确认的命令侧时序：Key 上升后，`VCU_BMS_target_state` 由 `7→2→3→4`，充电继电器控制由 `0→7`，放电继电器控制由 `0→1→2→3→4`；Key 下降后，目标状态和继电器控制返回非驱动码，`Model_Disabled_Out` 与 Key 同一采样点变化。

但本次不能确认完整高压闭环：`BMS_PrechargeContSts`、`BMS__PosBattContSts` 和 `BMS_Powerdown` 全程为 `0`，没有可用于确认预充完成、主接触器闭合或高压下电完成的正反馈。同时，`BMS__BattContFail=1` 持续 3.32 s 期间，已记录的 VCU 状态/继电器命令未发生变化；若该信号在项目定义中代表真实高压接触器故障，则应作为待确认风险，而非已经通过的紧急下电测试。

所有时间相对录波开始；状态码的业务含义尚未提供，以下仅按记录到的数值描述。

| 事件 | 时间 | 观测到的变化 | 相对 Key 边沿 |
| --- | ---: | --- | ---: |

| 第 1 次制动状态有效 | 5.460 s | `VCU_bBrakeSt: 0→1` | Key 上升前 300 ms |
| 第 1 次 Key 上电 | 5.760 s | `Key: 0→1`；`Model_Disabled_Out: 1→2` | 0 ms |
| 上电状态阶段 1 | 5.920 s | `VCU_BMS_target_state: 7→2` | 160 ms |
| 充电继电器命令 | 6.000 s | `VCU_charge_relay_control: 0→7` | 240 ms |
| 上电状态阶段 2 | 6.020 s | 目标状态 `2→3`；放电继电器 `0→1` | 260 ms |
| 上电状态阶段 3 | 6.520 s | 目标状态 `3→4`；放电继电器 `3→4` | 760 ms |

| 下电命令阶段 1 | 14.720 s | 目标状态 `4→2`；放电继电器 `4→0` | 100 ms |
| 下电命令阶段 2 | 14.840 s | 目标状态 `2→7`；充电继电器 `7→0` | 220 ms |

## 响应指纹

```text
正常上电（Key 0→1，制动已有效）
  Key                         +++  0→1
  Model_Disabled_Out          +    1→2，同一采样点
  VCU_BMS_target_state        阶梯 7→2→3→4，160–760 ms
  Charge relay command        +++  0→7，240 ms
  Discharge relay command     阶梯 0→1→2→3→4，260–760 ms
  BMS 预充/正极接触器反馈      0    全程为 0，未验证闭环

正常下电（Key 1→0）
  Key                         ---  1→0
  Model_Disabled_Out          -    2→1，同一采样点
  Discharge relay command     ---  4→0，100 ms（第 1 次）
  Charge relay command        ---  7→0，220 ms（第 1 次）
  VCU_BMS_target_state        阶梯 4→2→7，100–220 ms（第 1 次）
  BMS Powerdown feedback      0    全程为 0，未验证闭环

BMS 接触器故障（BMS__BattContFail 0→1→0）
  BMS__BattContFail           +++  置位 3.32 s
  VCU_BMS_target_state        0    故障窗口内保持 4
  Charge/Discharge command    0    故障窗口内保持 7 / 4
  VCU_Faultcode               0    全程为 0
  BMS Powerdown                0    全程为 0
```

## 判定与限制

| 检查项 | 判定 | 依据 |
| --- | --- | --- |
| Key 到模型使能反馈 | 已观察 | `Model_Disabled_Out` 每次与 Key 在同一记录点切换。其数值 1/2 的业务含义待确认。 |
| Key 上电到继电器控制命令 | 已观察 | 上电后 240–760 ms 内形成固定的目标状态及继电器控制阶梯。 |
| Key 下电到继电器控制撤除 | 已观察 | 第 1 次下电后放电/充电继电器控制在 100/220 ms 内撤除。 |
| 预充完成、高压主接触器闭合反馈 | 未验证 | 三个 BMS 反馈均恒为 0。 |
| BMS 接触器故障触发紧急下电 | 未观察到 | 故障置位 3.32 s 内，已记录控制命令、故障码和下电反馈未变化。 |
| `VCU_ModeReq` 作为状态机观测 | 无区分能力 | 全程为 0；不能用于本次状态转移判定。 |
| 模型重置/禁用输入 | 未触发 | `Model_Disabled=0`、`Model_Reset=0` 全程不变。 |
