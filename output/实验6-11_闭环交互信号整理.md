# 实验 6–11 闭环交互信号整理

依据《基础VCU与整车模型闭环交互实验.md》整理。本文中的信号是**实验逻辑信号**，不等同于已在 HIL 工程中确认的精确 `Veh_1.*` 接口路径；需要配置录波或脚本时，应再用接口目录、DBC 或 VCU 模型确认具体名称和量纲。

## 实验 6：百公里电耗预测闭环实验

| 类别 | 信号 |
| --- | --- |
| 工况/VCU 输入 | WLTC 工况、初始 SOC（90% / 60% / 30%）、整车实时 SOC、整车瞬时电流、整车实时车速。 |
| VCU 输出 | 预测百公里电耗。 |
| 整车模型输出/对照量 | 整车模型真实百公里电耗。 |
| 派生指标 | 电耗预测误差 = VCU 预测百公里电耗 − 整车真实百公里电耗。 |

## 实验 7：剩余续航里程计算实验

| 类别 | 信号 |

| 工况/VCU 输入 | WLTC 工况、实时 SOC、实时/瞬时百公里电耗。 |
| VCU 输出 | 预测剩余续航里程。 |

## 实验 8：整车上下电状态机闭环实验

| 类别 | 信号 |
| --- | --- |
| HIL/VCU 输入 | 钥匙 ON/OFF、刹车数字信号、BMS 高压就绪反馈报文、BMS 高压故障报文。 |
| VCU 输出 | `VCU_Mode` 工作状态码、主继电器控制指令、下电指令、动力允许/切断指令、故障 DTC 码。 |
| BMS/整车反馈 | 高压就绪状态、高压故障状态、预充完成状态/时延、高压闭合或断开状态。 |
| 关键状态路径 | `stand` 待机、`charge` 充电、`discharge` 驱动、`err` 故障。 |

## 实验 9：扭矩管理多模式交互实验

| 类别 | 信号 |
| --- | --- |
| HIL/VCU 输入 | 驾驶模式标识（ECO / 运动 / 蠕行）、加速踏板开度、制动踏板开度、挡位信号、WLTC 工况。 |
| VCU 输出 | 驱动扭矩请求、能量回收/回馈扭矩请求。 |
| 整车模型/MCU 反馈 | 实际执行扭矩、实时车速、制动回馈功率、单循环总电耗。 |
| 对比维度 | 峰值驱动扭矩、扭矩响应斜率、回馈扭矩/回收功率、低速蠕行扭矩、循环总电耗。 |

## 实验 10：VCU 基础 IO 节点功能测试

| 类别 | 信号 |
| --- | --- |
| VCU 输入通道 | 全部 AD 模拟输入通道、全部 DI 数字输入通道；每个通道的编号、标准输入值和信号类型。 |
| VCU 输出通道 | 全部 DA 模拟输出通道、全部 DO 数字输出通道；每个通道的编号、标准输出值和信号类型。 |
| 反馈/对照量 | VCU 采集值、VCU 输出值或通道回读值、通道正常/异常判定。 |
| 建议台账字段 | 通道编号、方向（AI/AO/DI/DO）、逻辑功能、标准输入、采集/输出实测值、允许误差、通过/失败、备注。 |

## 实验 11：CAN 网络交互基准实验

| 类别 | 信号 |
| --- | --- |
| VCU 接收输入（来自 BMS） | 电池 SOC、电池电压；对应 CAN 报文 ID、信号值、接收周期。 |
| VCU 接收输入（来自 MCU） | 电机转速；建议同步记录电机实际扭矩、电机电流等动力反馈；对应 CAN 报文 ID、信号值、接收周期。 |
| VCU 发送输出 | 控制扭矩报文/扭矩请求；对应 CAN 报文 ID、信号值、发送周期。 |
| 网络/总线状态 | 总线通信状态、各报文 ID、报文周期、丢帧/超时、报文偏移、校验/计数器状态（若 DBC 定义）。 |
| 整车对照量 | 与报文一致性核对所需的 SOC、车速、电机转速、电池电压、实际扭矩等整车模型状态。 |

## 汇总：每个实验的最小输入与输出

| 实验 | VCU 最小输入 | VCU 最小输出 | 必须同步记录的整车/ECU反馈 |
| --- | --- | --- | --- |
| 6 百公里电耗 | SOC、瞬时电流、车速、WLTC 工况 | 预测百公里电耗 | 真实百公里电耗。 |
| 7 剩余续航 | SOC、瞬时百公里电耗、WLTC 工况 | 预测剩余续航 | 理论真实可行驶里程。 |
| 8 上下电状态机 | Key、刹车、BMS 高压就绪/故障 | `VCU_Mode`、主继电器/下电/动力允许、DTC | BMS 高压状态、预充完成、主继电器实际状态。 |
| 9 扭矩管理模式 | 模式、加速/制动踏板、挡位、工况 | 驱动扭矩、回馈扭矩 | 实际扭矩、车速、回收功率、总电耗。 |
| 10 基础 IO | AD、DI 全通道标准输入 | DA、DO 全通道输出 | 通道回读/实测值和通道判定。 |
| 11 CAN 基准 | BMS SOC/电压、MCU 转速等接收报文 | VCU 控制扭矩等发送报文 | 报文 ID/周期/状态及模型物理状态。 |
