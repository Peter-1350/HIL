# FI-01 制动踏板故障分析报告（第 2 轮，含踏板输入）

## 结论

本轮新增记录了输入接口 `Veh_1.Driver.BrakePedal_perc`，因此已能直接验证 FI-01 的输入—输出映射。322 个采样点均满足以下关系（最大浮点残差不超过 `4.45e-16`）：

```text
P = clip(BrakePedal_perc, 0, 100)
BRK_Main_Out = 1.0 + 0.03 × P
BRK_Auxi_Out = BRK_Main_Out / 2
BrakeOpen1_Out = BrakeOpen2_Out = 2, 当 BrakePedal_perc > 0
BrakeOpen1_Out = BrakeOpen2_Out = 0, 当 BrakePedal_perc <= 0
```

结论如下：

- 50% 踏板对应 2.5 V / 1.25 V；100% 对应 4 V / 2 V。
- 150% 超量程输入仍使继电器激活，但模拟电压被钳位至 4 V / 2 V；输出端不能区分 100% 与 150%。
- -50% 负值输入被钳位为零制动：继电器为 0，模拟电压回到 1 V / 0.5 V 基线。
- 两路继电器在 322/322 个样本上相同；主辅电压在 322/322 个样本上严格 2:1。
- 输入变化与输出变化出现在同一个 200 ms 采样点。可判定记录分辨率内无额外采样周期延迟，但不能将其等同于真实控制链路的零延迟。

本轮 FI-01 的接口处理逻辑表现为**下限钳位、上限饱和、主辅比例输出和双继电器同步输出**，未发现接口失配。对于故障注入覆盖而言，150% 与 100% 的输出表现相同，负值输入与 0% 的输出表现相同；必须保留输入信号才能识别这两类越界故障。

## 故障分析

### 越界输入的可观测性

本次分别注入 -50% 和 150%。模型没有将它们原样传播至制动硬件输出，而是执行边界处理：负值归零，超量程封顶。因此，仅记录继电器和电压输出时，-50% 无法与 0% 区分，150% 无法与 100% 区分。这不是输出接口异常，而是输入合法化/饱和逻辑的直接证据。

若 FI-01 的测试目标是验证“非法输入是否被屏蔽”，本轮结果为通过；若目标是让下游 ECU 感知越界幅值，则现有模型接口无法实现，需要改在踏板输入前增加故障标志、诊断信号或记录原始注入命令。

### 小开度制动效果

在 2.556% 踏板、1.077 V 主制动输出条件下，车辆速度在 4.8 s 内增加约 4.35；而 50% 及以上的事件均出现约 13 单位/s 的速度下降。当前数据支持“该工况下小开度制动效果不明显”的结论，但无法精确确定制动生效阈值，因为 2.556% 与 50% 之间没有扫点，也未记录加速踏板、挡位和扭矩请求。

### 随机踏板输入

事件 5 中踏板在 0.115%～94.237% 间每 200 ms 变化一次，主、辅输出均逐点跟随且比例保持正确，继电器未出现抖动或释放。此前仅从输出侧看到的电压波动，在加入踏板输入后可确认是**注入输入变化的正常映射**，不是模型输出无因抖动。
