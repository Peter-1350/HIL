# FI-01 制动踏板故障分析报告（第 3 轮，工况信号补充）

## 结论

本轮在踏板输入和制动输出之外，补充记录了加速踏板、制动模式、驾驶模式、挡位和钥匙状态。结果进一步确认了第 2 轮得到的接口映射，并补足了车辆工况解释：

```text
P = clip(BrakePedal_perc, 0, 100)
BRK_Main_Out = 1.0 + 0.03 × P
BRK_Auxi_Out = BRK_Main_Out / 2
BrakeOpen1_Out = BrakeOpen2_Out = 2, 当 BrakePedal_perc > 0
BrakeOpen1_Out = BrakeOpen2_Out = 0, 当 BrakePedal_perc <= 0
```

在全部 376 个样本中，主电压映射最大残差为 `4.45e-16`，辅电压最大残差为 `2.23e-16`，两继电器不一致样本数为 0。由此可判定：**FI-01 输入在模型接口层被严格线性映射，并执行 0% 下限钳位与 100% 上限饱和。**

工况信号的核心发现如下：

- `AccPedal_perc` 从 9.600 s 起保持 100%。在此条件下，50%、100%、150% 及随机正制动踏板事件仍均伴随明显减速和母线电流降低，说明在本次模型工况中制动输入的车辆响应并未被满加速踏板抵消。
- -50% 制动踏板在相同的 100% 加速踏板、钥匙=1、挡位=1 条件下被钳位为无制动输出，车速从 139.923 上升至 158.004。这是负向越界输入被模型屏蔽的直接证据。
- 首段 100% 制动发生在钥匙和挡位尚未就绪的启动阶段，车辆接近静止；该段只可用于接口输出验证，不能用于评价行驶制动性能。
- `BrakeMode` 和 `DriveMode` 全程为 0。本次记录未提供枚举定义，不能将 0 解释为某个具体模式，但可以确认制动事件期间两者没有切换。

## 输入、输出与工况的联合判读

### 1. 满加速与制动叠加

事件 2、3、4、6 中加速踏板为 100%，但制动踏板为正后，继电器立即激活，主辅制动电压按映射输出，车辆速度在每段内均下降，且 BMS/MC 母线电流迅速降至接近零量级。这说明本次模型工况下，制动路径能够产生显著的减速效果。

这不等同于已经证明 VCU 的“制动优先”仲裁算法：当前只记录了驾驶员输入和模型输出，未记录扭矩请求、实际制动扭矩或仲裁状态。它是对**车辆级响应结果**的观察，而不是对内部仲裁逻辑的完整证明。

### 2. 越界输入的故障效果

- `BrakePedal_perc=-50%`：被下限钳位为 0%，输出与零踏板完全相同；在满加速工况下车辆继续加速。若 FI-01 的目标是验证非法负值不会误制动，则该项通过。
- `BrakePedal_perc=150%`：继电器仍正常激活，但主/辅电压封顶为 4/2 V，车辆级减速与 100% 事件同属满量程响应。若测试目标是让下游 ECU 识别超量程值，则仅凭当前输出接口无法达到，需要同步记录原始注入命令或诊断信号。

### 3. 随机踏板并非输出抖动

第 6 段主制动电压在 1.579～3.720 V 间变化，对应踏板随机输入 19.306%～90.672%。每一采样点都满足线性公式，辅助电压始终为主电压的一半，继电器始终保持激活。因此，这是注入波形的正常输出跟随，不是模拟量输出的无因抖动。
