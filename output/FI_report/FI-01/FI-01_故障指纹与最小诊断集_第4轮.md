# FI-01 制动踏板故障指纹与最小诊断集（第 4 轮，20 ms）

## 指纹定义

符号相对“同一工况下、注入前的稳定基线”解释：`+++` 强置位/增大，`---` 强撤除/降低，`0` 无故障诱发变化，`S` 为饱和而不可区分，`+→-` 表示状态量先受惯性继续上升、后转为下降。只有直接映射或已观察到稳定时间顺序的项列入主指纹。

## 正向制动需求（50% / 100% / 150%）

```text
BrakePedal_perc              +++   原始故障输入
BrakeOpen1_Out / 2_Out       ++    0 → 2，≤20 ms
BRK_Main_Out                 +++   1 → 2.5 V（50%）或 4 V（100%/150%）
BRK_Auxi_Out                 +++   始终为 BRK_Main 的一半
VCU_bBrakeSt                 ++    0 → 1，200–320 ms；反馈状态
VCU_BrakePedal_position      S     0 → 100；不区分 50%、100% 和 150%
VCU_Target_output_Torque     ---   140–300 ms 内降至基线 ≤5%
FTrq / RTrq                  ---   200–320 ms 内降至基线 ≤5%
MC_busbar_current            ---   200–320 ms 内降至基线 ≤5%
BMS_HVBusCurr                ---   240–340 ms 内降至基线 ≤5%
Vehspeed                     +→-   约 300–360 ms 达峰，随后下降
ABSActive / EBDActive        0     本轮未触发
Brakepump_Rely_state          0     本轮未触发
```

## 负向越界（-50%）

```text
BrakePedal_perc              ---   负值注入
BrakeOpen1_Out / 2_Out       0     保持 0/0
BRK_Main_Out / BRK_Auxi_Out  0     保持 1 / 0.5 V
VCU_bBrakeSt                 0     保持 0
目标/实际扭矩、母线电流      0*    未出现制动诱发的快速归零
Vehspeed                     +     5.08 s 内 85.16 → 149.71
```

`0*` 表示该量可随车速和驱动工况自然变化，但不具备正向制动案例中的快速撤除特征。150% 与 100% 的下游指纹相同，故必须记录 `BrakePedal_perc` 才能诊断超量程。

## 最小诊断集：9 个接口

| 层级 | 接口 | 必要性 |
| --- | --- | --- |
| 故障源 | `Veh_1.Driver.BrakePedal_perc` | 区分负值、超量程、卡死和随机波形；是区分 100%/150% 的唯一依据。 |
| 模拟执行 | `Veh_1.ToVCU.HW.Voltage Output.Voltage Output1.BRK_Main_Out` | 验证幅值映射、限幅和饱和。 |
| 数字执行 | `Veh_1.ToVCU.HW.Relay.Relay9.BrakeOpen1_Out` | 验证制动离散使能，与模拟通道互补。 |
| VCU 命令 | `Veh_1.FromVCU.CAN.VCU_Power.VCU_MC_TrqCtrl.VCU_Target_output_Torque` | 判断扭矩撤除请求是否出现。 |
| 前轴实际扭矩 | `Veh_1.PlantModel.PlantModel.Powertrain.FMotor.Motor.MotTrqManagement.FTrq` | 验证前轴实际动力响应。 |
| 后轴实际扭矩 | `Veh_1.PlantModel.PlantModel.Powertrain.RMotor.Motor.MotTrqManagement.RTrq` | 防止只看前轴而漏掉前后轴不一致。 |
| 电能响应 | `Veh_1.ToVCU.powerCAN_out.SoftMCUDataToBus.MC_motor_Torque_AND_speed.MC_busbar_current_ToBus` | 验证扭矩撤除是否传至电机母线。 |
| 车辆响应 | `Veh_1.PlantModel.PlantModel.Vehicle1.Vehspeed ` | 验证最终纵向风险；使用速度趋势而非瞬时值判定。 |
| 状态一致性 | `Veh_1.FromVCU.CAN.VCU_Body.GW_VCU_1.VCU_bBrakeSt` | 观察 VCU 制动确认；仅作反馈一致性，不单独用于推断因果。 |

## 最小集的判读

| 观测组合 | 诊断结论 |
| --- | --- |
| 踏板异常，但主电压和继电器不变 | 输入被限幅/屏蔽，或输入到执行接口的传播失败。 |
| 踏板为正，主电压变化但继电器未置位 | 数字执行支路异常，应扩大到双继电器记录。 |
| 执行接口已制动，目标/实际扭矩未撤除 | 控制命令或动力执行链异常，不应归因于踏板映射。 |
| 目标扭矩已撤除，前后实际扭矩仍高 | 电机或前后轴扭矩管理响应异常。 |
| 扭矩和 MC 电流已降，车速未在合理惯性时间后转降 | 检查机械制动、道路负载、车速信号或整车动力学。 |

## 不纳入最小集的信号

- `BrakeOpen2_Out`、`BRK_Auxi_Out`：本轮分别与主通道全程一致或固定 2:1；保留用于双通道冗余诊断。
- `FMotor.MotTrq`：本轮与 `FTrq` 等价，最小集不重复。
- `BMS_HVBusCurr_ToBus`：与 MC 母线电流同向，可作 BMS 侧交叉验证。
- `VCU_Target_output_MaxTorque`：本轮固定为 25，没有 FI-01 区分度。
- `VCU_BrakePedal_position`、`ABS/EBD`、`VCU_Brakepump_Rely_state`：本轮要么饱和、要么始终为 0；仅在通信、ABS/EBD 或液压制动专项工况中加入。
