# FI-04 挡位切换异常：故障指纹与最小诊断集（20 ms）

## 指纹定义

`+++` 表示强恢复/上升，`---` 表示强撤除/下降，`0` 表示未见切换诱发变化，`+→-` 表示车辆状态先受惯性继续上升、后转为下降，`0*` 表示未发生快速扭矩抑制但可有自然运行变化。符号仅用于固定 `Key=1、AccPedal=100%、BrakePedal=0` 的主测试段。

## 码 0 / 2 / 3：动力扭矩抑制指纹

```text
Gear_Button                  码值切入（0、2 或 3）
BrakeOpen1/2、BRK_Main/Auxi  0     保持制动未激活基线
VCU_Target_output_Torque     ---   40–160 ms 内降至切换前 ≤5%
FTrq / RTrq                  ---   220–260 ms 内降至切换前 ≤5%
MC_busbar_current            ---   220–260 ms 内降至切换前 ≤5%
BMS_HVBusCurr                ---   260–300 ms 内降至切换前 ≤5%
MC_motor_speed               -     随扭矩撤除下降
Vehspeed                     +→-   300–340 ms 达峰，随后滑行下降
VCU_bBrakeSt、ABS/EBD         0     本轮保持未激活
```

这个向量的核心不是“制动”，而是**在制动支路未激活时的动力扭矩撤除**。码值业务含义尚未明确，故不能直接称其为 N、R 或 P。

## 码 1：动力恢复指纹

```text
Gear_Button                  切回 1
VCU_Target_output_Torque     +++   60–140 ms 后恢复至 100 以上
FTrq / RTrq                  ++    100–340 ms 后恢复至 100 以上
MC_busbar_current            ++    100–340 ms 后恢复至 100 以上
Vehspeed                     -→+   短暂惯性后重新上升
制动执行与 ABS/EBD           0     保持未激活
```

## 码 5 / -1：未抑制动力的候选异常指纹

```text
Gear_Button                  5 或 -1
VCU_Target_output_Torque     0*    未降至切换前 ≤5%
FTrq / RTrq                  0*    未降至切换前 ≤5%
MC/BMS bus current            0*    未降至切换前 ≤5%
Vehspeed                     +     持续正向增加
制动执行与 ABS/EBD           0     保持未激活
```

若 `5/-1` 是非法码，该指纹意味着“非法码未触发已知的扭矩抑制行为”；若它们是项目定义的有效挡位，则它只是相应合法挡位的驱动指纹。必须取得枚举定义后才能作安全判定。

| 层级 | 接口 | 作用 |
| --- | --- | --- |

| 关键工况 | `Veh_1.Driver.AccPedal_perc` | 排除油门变化造成的扭矩变化。 |

## 最小集目前不能回答的问题

当前录波没有“实际挡位/挡位状态机/非法码诊断”信号，故只能判断**某个输入码带来的动力响应**，不能判断“控制器为何接受或拒绝该码”。下一轮应在上述 10 个接口之外至少补录：

```text
Veh_1.FromVCU.CAN.VCU_Body.GW_VCU_1.VCU_GearboxPositionDisplay
Veh_1.ToVCU.HW.Relay.Relay4.GearR_Out
Veh_1.ToVCU.HW.Relay.Relay5.GearN_Out
Veh_1.ToVCU.HW.Relay.Relay6.GearD_Out
Veh_1.ToVCU.HW.Relay.Relay7.GearP_Out
Veh_1.PlantModel.PlantModel.Driveline.RearMotSpd
```

前五项用于建立“输入码 → 实际/显示挡位”的映射；`RearMotSpd` 是静态依赖已确认的挡位敏感状态，可与后轴扭矩共同判断驱动链是否真正切断。

## 诊断判读

| 观测组合 | 诊断方向 |
| --- | --- |
| 挡位切换后目标扭矩未变、前后实际扭矩及电流未降 | 码值未触发扭矩抑制，或外部 VCU 命令覆盖了挡位处理。 |
| 目标扭矩降、实际扭矩不降 | 电机/扭矩执行链异常。 |
| 扭矩和电流降、制动输出不变、车速随后下降 | 动力撤除导致的滑行，符合本轮码 0/2/3 指纹。 |
| 输入码与 GearR/N/D/P 输出或显示挡位不一致 | 挡位译码、状态机或通信反馈异常。 |
| 码 5/-1 被定义为非法且仍保持驱动 | 非法码安全拒绝缺失的高优先级风险，应复现并检查诊断/降级设计。 |
