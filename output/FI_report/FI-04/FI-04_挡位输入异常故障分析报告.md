# FI-04 挡位输入异常故障分析报告

> 本报告基于早期约 200 ms 记录保留用于追溯。最新 20 ms 试验结果见 [FI-04_故障传播图_20ms.md](FI-04_故障传播图_20ms.md) 与 [FI-04_故障指纹与最小诊断集_20ms.md](FI-04_故障指纹与最小诊断集_20ms.md)。

## 结论

本轮 FI-04 记录了 `Gear_Button` 的 17 次变化，覆盖 0、1、2、3、5、-1 等码值及最短约 200 ms 的短脉冲。记录显示挡位变化会伴随 `VCU_TqReqCmd`、前/后轴扭矩、车速与母线电流的显著变化；但 `VCU_TqReqCmd` 在多数挡位变化点也同时变化，故**不能只凭本轮数据将扭矩变化完全归因于挡位输入本身**。

需要重点关注两段越界候选挡位：

- `Gear_Button=5` 持续约 4.8 s：加速踏板=100%、制动踏板=0%、Key=1，扭矩请求约 143.9→124.7，车速 160.85→175.62，持续正向增长。
- `Gear_Button=-1` 持续约 5.0 s：相同驾驶工况下，扭矩请求约 124.2→115.7，车速 176.01→182.61，仍持续正向增长。

若 5 与 -1 按项目定义属于非法挡位码，则上述表现没有显示出“拒绝非法码、切断扭矩或进入明确安全状态”的迹象，应列为**高优先级待确认问题**。不过，记录未包含 `Gear_Button` 枚举定义、挡位状态机或故障诊断位，不能仅由数值大小正式判定 5、-1 一定非法。

## 依赖关系与可归因性

```text
Gear_Button ──┐
Acc / Brake / Key ──> VCU 或控制逻辑 ──> VCU_TqReqCmd ──> RTrq / FTrq / FMotTrq ──> 车速、电流
             └────────────────────────> 挡位状态机
```

本轮的 `VCU_TqReqCmd` 在挡位切换点常发生同步变化。例如后半段在加速=100%、制动=0%、Key=1 固定时：

- 切到 0、2、3 时，扭矩请求在对应区间从约 142～145 退至 0；
- 切到 1 时，扭矩请求由 0 回升至约 140～146。

这表明挡位状态与扭矩请求之间存在强时序关系，但还不能区分“挡位状态机主动改变请求”和“试验脚本同时写入挡位及 VCU 请求”两种原因。要做因果判定，应在下一轮保持 `VCU_TqReqCmd` 不变、只改变 `Gear_Button`，或记录 VCU 的挡位状态、拒绝原因和故障位。

## 扭矩通道一致性

- `RTrq` 与 `VCU_TqReqCmd` 在全部样本上相等，最大差值为 0。
- `FTrq` 与前电机实际扭矩 `FMotTrq` 在全部样本上相等，最大差值为 0。
- `FTrq` 相对 `VCU_TqReqCmd` 的最大差值约为 30.93，说明前轴执行扭矩不总是完全等于 VCU 请求；可能涉及前后轴分配、执行限幅或动态过程。
- MCU 对外扭矩、转速与母线电流均随该扭矩链路变化。MCU 母线电流范围约 -55.64～942.22，BMS 母线电流范围约 -106.79～1780.02。

现有记录没有前后轴扭矩分配策略、扭矩限值和保护状态，不能将 30.93 的差值直接认定为故障。

## 故障判定

| 检查项 | 判定 | 依据 |
| --- | --- | --- |
| 挡位变化是否影响动力链路 | 观察到影响 | 多个挡位变化点伴随扭矩请求、扭矩、车速和电流变化。 |
| 非法候选码 5 / -1 是否被安全拒绝 | 待确认，存在风险迹象 | 两段均保持正扭矩和持续加速；需枚举定义确认其非法性。 |
| 挡位恢复后的动力状态 | 观察到恢复过程 | 复位后多次在挡位 1 与其他码之间出现扭矩请求退坡/回升。 |
| 挡位变化到扭矩变化的精确延迟 | 无法判定 | 挡位和 VCU 请求常同一采样点变化，采样仅约 200 ms。 |
| VCU 请求到后轴扭矩管理量 | 通过 | `RTrq = VCU_TqReqCmd`，全样本无差异。 |
| 前轴执行扭矩与请求一致性 | 待评估 | 最大差约 30.93，需扭矩分配/限值定义。 |

## 下一轮建议

1. 明确 `Gear_Button` 的枚举表与“非法码”集合，并记录挡位状态机当前状态、拒绝原因和诊断故障位。
2. 做单变量试验：固定 Key=1、AccPedal=100%、BrakePedal=0%、`VCU_TqReqCmd` 为常数，仅依次注入 0、1、2、3、5、-1。
3. 分别测试行驶中切换、静止切换和 10～50 ms 短脉冲，记录挡位变化至扭矩置零/恢复的延迟。
4. 增加前后轴扭矩请求、扭矩分配比例、扭矩限值、扭矩保护与故障状态，判定前轴 30.93 的执行差是否合理。
5. 将采样周期提高到 10～20 ms，避免 200 ms 采样掩盖瞬态挡位保护行为。
